최신 요청에 따라 실제 Airbnb Pool 광고를 참고해 10초 한국어 구성으로 재기획했습니다. 원본 광고의 공식 대본이나 컷별 복원본이 아닙니다.

미디어 생성·영상 제작은 별도 안내에서 제외하므로 수행하지 않았습니다. 씬의 도구명은 제작 예정 도구이며, 입력 프롬프트·출력 결과 요약·생성 결과 파일명은 공란입니다.

실제 Airbnb를 광고 대상으로 선택한 것은 사용자 요청에 따른 범위 변경으로, 본문의 여행지 추천 웹 서비스 고정 조건과는 다릅니다.
